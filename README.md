# Tabulate

Split any receipt in under a minute. Scan the bill, tap who had what, and send
one link. Tabulate works out everyone's share of tax, tip and discounts, exact
to the cent.

Live: [tabulate.vercel.app](https://tabulate.vercel.app/)

## Features

- **Receipt scanning.** Upload a photo and Gemini extracts the items, tax, tip
  and discounts. If the lines don't add up to the printed total you are told.
- **Flexible splits.** Share an item equally, by shares, by percent or by exact
  amounts. Split one line into parts or duplicate it.
- **Exact maths.** Money is integer cents everywhere and remainders are
  distributed with the largest remainder method, so totals always reconcile.
- **Share links.** Anyone with the link sees what they owe. No account needed
  to view.
- **Accounts.** Sign in with Google to keep, edit and delete
  your tabs.
- **Payment note.** Set a message such as "Please e-transfer me at
  you@example.com" once in Settings. It appears on every tab you share and in
  the message you copy.

## Stack

Next.js 16 (App Router, React 19, React Compiler) · TypeScript 7 · Tailwind CSS
4 with shadcn/ui · Supabase (Postgres, Auth, Storage) · Vercel AI SDK with
Gemini · React Hook Form and Zod 4.

## Project layout

```
app/                  Routes. (marketing) is static, (app) is the signed-in area
  api/receipts/parse  Authenticated, rate limited receipt scanning endpoint
  auth/callback       Completes Google and email-link sign in
components/           Shared UI (components/ui is generated by shadcn)
features/
  tabs/               Schema, split maths, queries, server actions, tab view
  tab-editor/         The four step create/edit flow
  receipts/           Model prompt, output normalisation, upload client
  auth/ settings/     Sign in and profile
lib/supabase/         Browser, server and proxy clients, generated DB types
proxy.ts              Refreshes the session and gates the signed-in area
supabase/migrations/  The whole database: tables, RLS, functions, storage
```

## Data model

| Table              | Purpose                                                       |
| ------------------ | ------------------------------------------------------------- |
| `profiles`         | One per user: display name, payment note and home currency    |
| `tabs`             | A receipt: owner, name, date, currency, tax, tip, discount, image path, and what it was charged as in another currency |
| `tab_participants` | People on a tab, and whether each has paid                    |
| `tab_items`        | Line items with a price and split type                        |
| `item_shares`      | Who shares which item, with a weight                          |
| `receipt_scans`    | Scan log used to rate limit the AI endpoint                   |

Every table has row level security and is writable only by the tab's owner.
Shared links are read through one `security definer` function,
`get_shared_tab(slug)`, so the tables themselves are never exposed to anonymous
visitors. Tabs are written atomically through `save_tab()`. The app never uses
the Supabase secret key.

## Running locally

1. Install dependencies:

   ```bash
   npm install
   ```

2. Create `.env.local`:

   ```bash
   # Supabase dashboard → Project Settings → API
   NEXT_PUBLIC_SUPABASE_URL=https://<your-project-ref>.supabase.co
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
   # Google AI Studio key, used server-side only for receipt scanning
   GEMINI_API_KEY=...
   # Optional, defaults to gemini-2.5-flash
   # GEMINI_MODEL=gemini-2.5-flash
   # Optional Groq key. Receipts are read by Groq when Gemini is rate limited or down
   # GROQ_API_KEY=...
   # Optional, defaults to qwen/qwen3.8-27b
   # GROQ_MODEL=qwen/qwen3.8-27b
   ```

3. Apply the schema to your Supabase project:

   ```bash
   npx supabase link --project-ref <your-project-ref>
   npx supabase db push --remote
   ```

4. In the Supabase dashboard, under **Authentication**:
   - **URL Configuration**: set the Site URL to your production URL and add
     `http://localhost:3000/auth/callback` and
     `https://<your-domain>/auth/callback` to the redirect URLs.
   - **Providers → Google**: enable it and paste the client ID and secret from
     a Google Cloud OAuth client. Its authorised redirect URI is
     `https://<your-project-ref>.supabase.co/auth/v1/callback`.
   - Email sign-in links work out of the box. Configure custom SMTP before
     going to production, because the built-in mailer is heavily rate limited.

5. Start the app:

   ```bash
   npm run dev
   ```
